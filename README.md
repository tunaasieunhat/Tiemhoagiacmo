| Cách chơi | Link |
|---|---|

Game 3D chibi trồng hoa & bán hoa, chạy trên trình duyệt (điện thoại + máy tính).
Công nghệ: Three.js + Vite, sau này dùng Supabase cho tài khoản online.

## Chạy thử trên máy tính

1. Cài **Node.js** (bản LTS) tại https://nodejs.org → bấm tải, cài như phần mềm bình thường.
2. Tải code về: trên GitHub bấm nút xanh **Code → Download ZIP**, rồi giải nén.
3. Mở cửa sổ lệnh trong thư mục vừa giải nén:
   - Windows: mở thư mục, bấm vào thanh địa chỉ, gõ `cmd` rồi Enter.
   - Mac: chuột phải thư mục → *New Terminal at Folder*.
4. Gõ lần lượt (chỉ cần lần đầu gõ dòng 1):
   ```
   npm install
   npm run dev
   ```
5. Mở trình duyệt vào địa chỉ hiện ra, thường là **http://localhost:5173**

**Chơi trên điện thoại (cùng Wi‑Fi với máy tính):** mở địa chỉ dòng `Network: http://192.168.x.x:5173` hiện ra ở bước 4.

## Chỉnh số liệu cân bằng

- `data/flowers.js` — từng loài hoa (thời gian lớn, số lần tưới/ngày, phân bón, giá...)
- `data/config.js` — tốc độ ngày đêm, mức héo, đồ khởi đầu, camera, bật/tắt công cụ thử nghiệm (`DEV_TOOLS`)
- `data/shop.js` — giờ mở cửa, tần suất khách, độ kiên nhẫn, giá theo sao, tiền bo, uy tín, các dịp tặng hoa
- `data/wrapping.js` — giấy gói, ruy băng (màu, tông, giá, cấp mở khóa, số lượng khởi đầu)
- `data/market.js` — giá phân bón, các nâng cấp (giá, cấp cần, tác dụng), giá & cấp mở rộng đất
- `data/levels.js` — XP cần cho mỗi cấp, XP mỗi việc, thưởng lên cấp
- `data/variants.js` — các màu hoa (màu sắc, tông, ý nghĩa, độ hiếm, công thức lai), thời gian lai, thưởng sổ tay
- `data/regulars.js` — khách quen: câu chuyện, yêu cầu, phần quà từng chương
- `data/quests.js` — mẫu nhiệm vụ & phần thưởng
- `data/automation.js` — máy móc & nhân viên (giá, lương, cấp)
- `data/decor.js` — đồ trang trí & vị trí đặt
- `data/contest.js` — chủ đề cuộc thi & thưởng theo hạng
- `data/seasons.js` — độ dài mùa, ảnh hưởng mùa, xác suất thời tiết/thiên tai/dịch bệnh theo mùa, mức thiệt hại, đồ phòng hộ, các lễ hội
- `data/customers.js` — tên, ngoại hình, câu nói của khách
- `data/changelog.js` — ghi chú hiện cho người chơi khi có bản cập nhật
- `data/online.js` — địa chỉ & khóa công khai Supabase, tần suất đồng bộ
- `data/badwords.js` — từ cấm (bản chính nằm trong bảng `banned_words` trên Supabase)

Sửa số → lưu file → trình duyệt tự cập nhật.
